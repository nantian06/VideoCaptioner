# 审计与重构说明（本地中文定制版 v1.5.0）

对原版 VideoCaptioner 的 LLM 断句、纠错、翻译、字幕样式、视频合成、批量处理、视频下载、配音做了一遍走查，找出「用起来不舒服」的根源，并按优先级改了一部分。

## 一、用起来不舒服的根源

1. **看不见这次要做什么。** 主页按 ▶ 就自动串起「转录 → 优化/翻译 → 合成」，没有总览也没有确认。断句开关藏在「字幕优化」页右上角齿轮的对话框里；默认会**硬字幕重新编码整段视频**，几个小时的直播录像要跑很久。
2. **同一个设置散在好几处。** 转录模型、校正/翻译开关、字幕布局、软/硬字幕，在「设置」页和各工具栏里各有一份。虽然大多会同步，但改了哪里、哪个生效，用户心里没底。
3. **输出乱放、还会覆盖文件。**
   - 字幕写进 `work-dir`，同时又在原视频旁边写一份 `<视频名>.srt/.ass`，会覆盖同名文件。
   - 合成视频放在原视频旁边，文件名是 `【卡卡】xxx.mp4`。
   - 字幕页手动点「开始」会**用 SRT 内容覆盖输入文件**（输入是 .ass 时直接损坏）。
4. **失败是静默的。**
   - LLM 校正失败的批次会原样返回，界面照样提示「优化完成」。
   - 改了 LLM 地址或 Key 必须重启才生效，而「检查连接」又能通过，容易误导。
   - 只要识别结果带字级时间戳，就**一定**走 LLM 断句，没配 LLM 就报错。
5. **取消不了。** 转录和合成线程没有停止方法，点取消没反应。字幕线程的取消也停不掉 LLM 优化器。
6. **批量页是黑盒。**
   - 页面上看不到用的什么配置，处理中途改设置会影响后面的文件。
   - 不能单行取消或重试，「清空」会卡住界面直到当前转录结束。
   - 「打开文件夹」打开的是源目录，字幕却在 work-dir。
7. **联网行为。**
   - 每次启动都请求作者服务器检查版本。
   - 服务器可以下发「强制更新」，禁用主页和批量页。
   - 还有远程公告、捐赠、推广卡片。
   - 默认的 B 接口会上传音频，并且有本地限额：12 小时 360 分钟、100 次。
8. **功能只在命令行里有。** 配音（TTS）、样式预设覆盖、`doctor` 只有命令行版本。命令行和界面各用一套配置文件。

## 二、这次改了什么

| 问题 | 改动 |
|---|---|
| 看不见流程 | 任务创建页加了「**处理方案**」卡片：识别 / 断句 / 校正 / 翻译 / 视频五行，直接改，并显示输出位置和提醒（没填 LLM Key、云端接口会上传、硬字幕很慢）。批量页顶部显示同一份方案，可跳回修改。 |
| 默认太重 | 默认引擎改为本地识别，语言中文，**默认只出字幕**；视频选项为 只出字幕 / 软字幕 / 硬字幕。 |
| 断句依赖 LLM | 断句成为一等设置：「按标点和停顿」（本地规则，免 LLM，默认）或「LLM 智能断句」。本地引擎自己按标点、停顿和每行字数组句。 |
| 输出乱放 | 所有产物都放在 `work-dir/<视频名>/`；不再往原视频旁边写字幕。字幕页编辑后另存为 `xxx【编辑后】.srt`，不覆盖输入。批量合成的视频输出为 `<视频名>_字幕版.mp4`。 |
| 静默失败 | LLM 客户端按地址和 Key 缓存，改了立即生效；校正有失败批次时弹出警告；完成提示改为如实描述。 |
| 取消 | 转录可以取消，本地引擎会在下一个片段处停下。字幕取消能停掉优化器。 |
| 联网 | 删除版本检查、远程公告、强制更新开关、捐赠和推广卡片。Linux 上缺 `xdg-open` 时打开文件夹不再崩溃。 |
| 文件名 | 原始字幕文件名用「本地-sensevoice」这类短标签，不再把「B 接口」「✨」写进文件名。 |

## 三、这次没改的（以及原因）

| 项目 | 现状 | 原因或建议 |
|---|---|---|
| 配音界面 | 仍然只有命令行（`vc.sh dub`） | 你的主要场景是出字幕，配音界面工作量大，单独排期 |
| 批量页单行取消/重试 | 未做；「清空」仍可能卡住界面 | 需要给合成线程加停止并重写队列，下一步做 |
| 下载器选项 | 未加（只下音频、清晰度、cookies 选择） | 下一步做 |
| 命令行与界面配置合一 | 仍是两份配置文件 | 改动面大；本地模型目录两边已共用 |
| ASR 引擎注册表 | 未做；加引擎仍需改十几处 | 属于内部重构，对使用无直接影响 |
| 设置项去重 | 重复项还在，但都同步 | 「处理方案」已经成为主入口 |
| B/J 接口限额 | 保持原样 | 默认已改为本地识别，不再依赖它们 |
| 配置按阶段读取 | 中途改设置会影响后续阶段 | 需要「方案快照」，和批量页重写一起做 |

## 四、给以后加功能的备注

新增一个识别引擎需要改的地方（本次加本地引擎就是按这个清单改的）：

1. `core/entities.py`：枚举、语言能力表、TranscribeConfig。
2. `core/asr/`：引擎实现和 `transcribe.py` 分发。
3. `ui/common/config.py`：配置项。
4. `ui/task_factory.py`。
5. `ui/components/transcription_setting_card.py` 和引擎设置组件。
6. `ui/view/setting_interface.py`。
7. 命令行：`cli/main.py`、`cli/config.py`、`cli/validators.py`、`cli/commands/{transcribe,process,doctor}.py`。
8. 测试和文档。
